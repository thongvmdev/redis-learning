# Giáo án học Redis (6 Chương — bản cập nhật, tailor theo stack Node.js/Next.js)

Đã điều chỉnh Chương 6 để khớp với stack thực tế của em (Node.js/Next.js thay vì đủ 3 ngôn ngữ), và gắn ví dụ thực hành vào project Family Finance + pipeline Weaviate.

| Chương                                           | Nội dung chính                                                                                                                                                                                                                                                                                                                                                                | Kết quả đạt được (Key Takeaways)                                                                                                                        |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Chương 1: Giới thiệu & Tổng quan**             | • Redis là gì? Tại sao chọn Redis?<br>• So sánh In-Memory Database vs Relational Database (liên hệ MySQL em đang dùng cho Family Finance)<br>• Cài đặt Redis qua Docker (ưu tiên, vì em đã quen Docker Compose)<br>• Làm quen Redis CLI và RedisInsight (GUI)                                                                                                                 | Nắm khái niệm cơ bản, dựng môi trường local, thao tác được với Redis server qua CLI/GUI.                                                                |
| **Chương 2: Cấu trúc Dữ liệu cơ bản & Nâng cao** | • Strings: Set, Get, Expiration (TTL)<br>• Lists: Queue, Stack (LPUSH, RPOP)<br>• Hashes: Lưu Object/User profile<br>• Sets & Sorted Sets (ZSet): Dữ liệu không trùng lặp, Leaderboard<br>• Geospatial & Bitmaps & HyperLogLog: Tọa độ, điểm danh, đếm dữ liệu lớn                                                                                                            | Thành thạo chọn kiểu dữ liệu phù hợp cho từng bài toán thực tế (User profile, giỏ hàng, category cache, bảng xếp hạng).                                 |
| **Chương 3: Lưu trữ Bền vững & Bộ nhớ**          | • RDB (Snapshots): nguyên lý, ưu/nhược điểm<br>• AOF: chính sách fsync (always, everysec, no)<br>• Memory Eviction Policies: LRU, LFU, Volatile-TTL khi RAM đầy                                                                                                                                                                                                               | Cấu hình lưu trữ để tránh mất dữ liệu, tối ưu RAM server.                                                                                               |
| **Chương 4: Tính năng Nâng cao**                 | • Transactions: MULTI, EXEC, WATCH<br>• Pub/Sub: Real-time messaging/chat<br>• Redis Streams: xử lý event-driven (so sánh nhanh với Kafka)<br>• Lua Scripting: logic phức tạp nguyên khối (atomic ops)                                                                                                                                                                        | Làm chủ xử lý bất đồng bộ, real-time messaging, giao dịch an toàn.                                                                                      |
| **Chương 5: High Availability & Scaling**        | • Replication: Master-Replica (Read scaling)<br>• Redis Sentinel: failover tự động<br>• Redis Cluster: sharding qua Hash Slots                                                                                                                                                                                                                                                | Thiết kế hệ thống Redis chịu lỗi cao, hiểu lý thuyết dù project cá nhân chưa cần scale tới mức này — quan trọng cho phỏng vấn fullstack/backend senior. |
| **Chương 6: Tích hợp & Dự án Thực tế**           | • Tích hợp Redis vào Node.js/Next.js (`ioredis`)<br>• **Thực hành 1:** Cache-aside layer cho REST API — áp dụng cache category list hoặc kết quả search Weaviate (trước bước LLM judge trong retry-loop pipeline)<br>• **Thực hành 2:** Rate Limiter cho insight-chat router (giới hạn query semantic/SQL mỗi user/phút)<br>• **Thực hành 3:** Session & JWT token management | Đưa Redis vào Family Finance thực chiến: giảm latency pipeline search, chống spam router, quản lý session an toàn.                                      |

---

Cấu trúc 6 chương phủ đủ chiều sâu để dùng cho phỏng vấn senior/fullstack lẫn ứng dụng thực tế. Nếu muốn, tôi có thể triển khai chi tiết Chương 6 – Thực hành 1 (cache-aside cho pipeline Weaviate) thành code mẫu cụ thể trước, vì đây là phần áp dụng ngay được vào Family Finance.
